Migrador de Planilhas para SQL

Envie sua planilha (.xlsx ou .csv) para gerar automaticamente o script SQL de migração.

📋 Colunas Detectadas na Planilha:
Usada para identificar registros existentes nos modos "Apenas Inserir" e "Substituir". Por padrão, a primeira coluna marcada.
🔎 Script de Consulta (opcional)

Gera um script pra rodar no banco de destino do cliente e descobrir a estrutura real da tabela (nome, tipo e tamanho de cada coluna) antes de aplicar a migração.

Opcional. Quando preenchido, o script gerado usa o tipo REAL de cada coluna do banco de destino (em vez de adivinhar pela planilha) — evita erro de conversão nos modos "Apenas Inserir" e "Substituir".
🔗 Mapeamento de Colunas (Planilha → Banco de Destino)

Escolha pra qual coluna do banco cada coluna da planilha vai. Colunas com o mesmo nome já vêm pré-selecionadas.
